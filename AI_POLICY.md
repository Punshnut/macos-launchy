# AI Policy

It's okay to use AI (i.e., LLMs) as a coding tool here. That said, contributions
to this project are held to a high bar, and the project maintainers remain
responsible for any code that ships in a release. Whatever tools you used to
write it, you're expected to stand behind the code you submit.

**Please don't use AI to write comments addressed to maintainers.** Comments
are expected to be written by humans, in their own words. A comment that reads
as AI-generated may be hidden without notice.

When you open an issue, describe the problem yourself, in your own words.

When you open a pull request, you should be able to explain the change, both
in the PR description and in follow-up discussion, without leaning on an AI
to answer for you. **Don't paste AI-generated responses into a reply to a
maintainer's question.**

A human needs to be in the loop who actually understands what the AI produced.
**Autonomous agents submitting contributions on their own are not welcome
here**, and pull requests that look like they came from one may be closed
without notice.

Want to quote something an AI said as supporting context? That's fine, but
put it in a quote block (using `>`), say plainly that it's AI output, and add
your own explanation of why it's relevant. Keep quoted snippets short.

AI can be a real help if English isn't your first language. If you're using
it to polish your wording, make sure the result still sounds like you. For
translations, we'd rather you write in your native language and include the
AI translation in a quote block alongside it.

This policy is adapted from [uv's AI policy].
